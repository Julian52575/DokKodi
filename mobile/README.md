# DokKodi mobile

Expo / React Native app (NativeWind styling), built for Android. From the repo
root, in the Nix shell (entering it in a terminal installs the Android SDK
the first time and asks you to accept Google's licences):

```bash
just mobile-start    # Expo dev server
just mobile-android  # run on a device or emulator
just mobile-apk      # release APK
just mobile-check    # eslint, prettier, tsc
```

`mobile/android` is generated by `expo prebuild` and git-ignored.
